# Small Gap RSA (Medium)

RSA standar... atau bukan? Perhatikan baik-baik bagaimana p dan q dipilih.

**Files:** `output.txt` (berisi n, e, c)

**Format flag:** `CTF{...}`

## Hint
- Kalau p dan q sangat berdekatan nilainya, ada teknik factorization klasik
  yang jauh lebih cepat dari brute force biasa (cari di Google: "Fermat
  factorization method").
